| Stage | Your responsibility |
|---|---|
| Attempt | Work for25–40 minutes and describe expected behavior, observations, and errors |
| Ask | Request a hint, explanation, or focused review rather than an entire implementation |
| Implement | Write, run, and test the solution yourself |
| Verify understanding | Explain the code and make a small requirement change without copying |
| Review labels | Human-review evaluation labels and important decisions |
| Protect data | Understand what is sent to a service; never include secrets or private journals casually |
| Record evidence | Identify what you built, what failed, why you chose an approach, and how to reproduce it |

A working solution you cannot explain is still a learning gap. AI may review a test; it does not turn unreviewed model output into ground truth.
