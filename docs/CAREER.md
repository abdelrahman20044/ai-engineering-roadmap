The Native AI brochure lists programming/DSA, SQL, Git/CLI, conceptual mathematics, and technical English as preparation. Questions below are inferred practice prompts, not confirmed ITI interview questions.

| Area | Practice task |
|---|---|
| Python/FastAPI | Write a typed endpoint and fixture; explain blocking I/O and cleanup |
| Mathematics/ML/DL | Calculate cosine and precision/recall; explain leakage, autograd, and inference versus training |
| RAG | Isolate retrieval failure from generation failure; distinguish reference validity from supporting evidence |
| Context | Decide what to truncate and how to correct/delete stale memory |
| Agents/MCP | Justify an agent over a workflow and locate authorization and protocol boundaries |
| LLMOps | Diagnose a trace, demonstrate rollback/recovery, and explain evaluation regression and cost |

| Target role | Additional portfolio evidence |
|---|---|
| Junior AI Application Engineer | LLM integration, typed outputs, RAG, evaluation, isolation, and deployment |
| Junior LLM/RAG Engineer | Parsing/retrieval comparisons, evidence labels, citation review, and failure analysis |
