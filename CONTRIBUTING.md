# Maintaining the Roadmap

[Home](README.md)

| Change | Required follow-up |
|---|---|
| Module prerequisites or tasks | Update curriculum.json and the module Markdown together |
| Official syllabus claim | Verify the source/version/date and preserve uncertainty |
| Chapter assignment | Confirm the actual table of contents and page convention |
| Documentation/link changes | Run validate.py and tooling tests |
| Reader changes | Rebuild OVERVIEW.html with optional Pandoc |
| Progress | Record actual evidence, not generated completion claims |
| Publishing | Review rights, secrets, personal data, and your chosen license |

Validation checks structure and links, not editorial quality or skill mastery. Templates and sample data are not completed experiments. The package does not redistribute books or automatically license external materials.
