# Resource library authoring template

Every numbered Level has `README.md` and `resources.md`. The library is a set of choices supporting the Level's topic map, not a second mandatory syllabus.

| Category | What to include |
| --- | --- |
| Start here | The short primary path and resource-selection rule. |
| 1 · Arabic and Egyptian materials | Instructor/organization, direct lesson, language, free/paid access, topic mapping and scope limitation. Label translations accurately. |
| 2 · English video and guided teaching | Individual lecture/course outline, relevant subjects, bounded assignment, version caveat and enrollment terms. |
| 3 · Slides, notebooks and repositories | Runnable companion material; distinguish educational examples from production guarantees. |
| 4 · Paid alternatives | A concrete reason to buy, relevant topics and free alternative; “none needed” is a valid decision. |
| 5 · Books and article | Supplied-PDF chapter/section locators, read/skim/defer guidance and duplicate-reading avoidance. |
| 6 · Practice, labs and quizzes | External assessment type plus the Level's original practical checkpoints and required evidence. |
| 7 · Official references | Narrow implementation/spec sections and the exact problem they resolve. |
| 8 · Advanced reading | Optional deeper material with a trigger for using it; no required filler. |
| Choosing and stopping | Explain diagnostic skips, language choice, source overlap and when to move on. |
| Verification | Check date, author/publisher scope evidence, reachability record and unresolved access limitations. |

Each resource row must answer: who made it, which language/format, what it costs, which topic it covers, what to do with it, and what it does not cover. Do not use a channel homepage, an unverified playlist, a translated subtitle label, or an old price as a shortcut.
