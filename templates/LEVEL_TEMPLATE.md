# Level learning-journey authoring contract

[Home](../README.md) · [Resource card template](RESOURCE_LIBRARY_TEMPLATE.md)

Level pages are generated by `scripts/render_learning.py`. Edit `curriculum.json`, `docs/RESOURCE_CATALOG.json` and `docs/reading_plan.json`, then render. Do not create competing chapter schedules in Markdown.

## Required README structure

1. Title, navigation, tier/difficulty/priority and personal hours.
2. Outcomes and prerequisite links; link the diagnostic in `details.md`.
3. Prominent **Start Here / Recommended Learning Path** with a next action.
4. Ordered steps. For each step provide:
   - **Learn:** concrete concepts/subtopics.
   - **Required reading:** ledger ID, exact portion and first-use/review status. Use “None” where the books do not cover the topic.
   - **Primary · Resource Type:** one link and a bounded assignment. If the book is sufficient, select that book slice rather than add a redundant tutorial.
   - **Practice:** an implementable task.
   - **Completion check:** observable behavior or evidence.
   - A direct link to the matching `resources.md#unit-XX` group, whose tables explain topic-specific choices.
5. Assessed exercises with pass criteria, readiness checklist, capstone gate/evidence, defer list, progress command and unlocked Levels.

## Supporting files

- `resources.md`: comprehensive topic-grouped tables with explicit choice/sequence rules; no second book schedule.
- `details.md`: diagnostics, complete scope, pitfalls, original questions/answer guide and official ITI provenance.

README pages use prose and checklists, not parallel resource/book tables. Preserve technical research, existing tasks and criteria. A prominent next action is a design heuristic; actual comprehension requires learner feedback.
